## Project Overview

This project is a multi-page personal portfolio website developed using HTML5 and CSS3. The website showcases my background, technical skills, projects, and contact information. The purpose of the project is to demonstrate semantic HTML, responsive web design, accessibility principles, CSS styling techniques, and best coding practices.

---

## Issues Found

The starter code contained several issues:

- Inconsistent indentation and formatting
- Poor page alignment and spacing
- Minimal semantic HTML structure
- Limited accessibility features
- Navigation links lacked consistency
- Form element alignment issues
- Footer alignment problems
- Missing responsive design techniques
- Limited commenting and code documentation

---

## Fixes Implemented

The following improvements were made:

- Added semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, and `footer`
- Corrected indentation and formatting throughout all files
- Improved page layout using Flexbox and CSS Grid
- Fixed alignment issues in forms, tables, images, and navigation menus
- Added meaningful comments explaining major sections
- Improved responsiveness using media queries
- Added hover and focus states for better usability
- Added descriptive alt text to images
- Styled tables, forms, and project cards consistently
- Improved footer structure and alignment

---

## Final HTML Structure

The website uses semantic HTML5 elements to improve readability and accessibility:

- `header` for branding and navigation
- `nav` for site navigation links
- `main` for page content
- `section` for logical content grouping
- `article` for project cards
- `table` for experience and skills information
- `footer` for contact information and copyright details

This structure improves maintainability, accessibility, and search engine friendliness.
