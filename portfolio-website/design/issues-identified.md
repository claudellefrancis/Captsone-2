# Issues Document

# Issues Found and Fixed During Development

- Header content was not aligned correctly. Fixed using Flexbox alignment properties.
- Navigation menu had no styling. Added spacing, hover effects, and improved readability.
- Navigation links lacked visual feedback. Added :hover pseudo-class styling.
- Colour contrast between text and background was too low in some sections. Adjusted colours for better accessibility.
- Hero section layout was not responsive. Implemented CSS Grid for improved structure.
- Hero image sizing was inconsistent. Added width constraints and object-fit styling.
- Buttons had limited visual hierarchy. Improved colours, padding, and hover states.
- Form inputs stretched inconsistently. Applied uniform width and spacing.
- Checkbox alignment was incorrect. Used Flexbox and spacing adjustments.
- Radio buttons displayed unevenly. Added fieldset styling and proper alignment.
- Form fields lacked focus indicators. Added :focus styles to improve usability.
- Table borders were missing or inconsistent. Added borders and collapsed table spacing.
- Table rows were difficult to read. Added alternating row colours using nth-child().
- Project cards lacked interaction feedback. Added hover effects and transitions.
- Mobile responsiveness was inadequate for the projects section. Added a media query for smaller screens.
- Footer alignment was inconsistent with page layout. Updated spacing and centering.
- CSS code formatting was inconsistent. Improved indentation, comments, and organisation.
- Missing selector variety. Added element, class, ID, descendant, attribute, and pseudo-class selectors to meet requirements.

Total issues identified and resolved: 18
