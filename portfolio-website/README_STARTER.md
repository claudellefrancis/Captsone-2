1. Project Overview

This project involved debugging and completing a portfolio website for a creative agency. The starter code contained HTML, CSS, accessibility, and styling issues that were fixed to create a professional, responsive, and accessible four-page website.

2. Issues Found

Key issues included:

Missing navigation menu
Overuse of <div> elements
Missing semantic HTML5 tags
Missing image alt text
Missing table on About page
Incomplete contact form
Missing form labels and validation
Poor colour contrast
No hover or focus effects
Missing table and form styling
Inconsistent layout and spacing
Limited CSS selector usage
3. Fixes Implemented
Added semantic HTML elements (header, nav, main, section, footer)
Created navigation on all pages
Added descriptive alt text to images
Added a skills table on the About page
Completed the contact form with validation
Added a third project section
Improved typography, colours, spacing, and layout
Added hover and focus effects
Organized and cleaned up CSS
4. HTML Structure & Semantic Elements

The website contains four pages:

Home
About
Projects
Contact

Semantic elements used include:

<header>
<nav>
<main>
<section>
<article>
<footer>

These improve structure, accessibility, and readability.

5. CSS Styling Approach

The styling focuses on:

Consistent colour scheme
Responsive layouts using Flexbox
Styled navigation, forms, and tables
Hover and focus effects
Proper use of margins, padding, and borders
Multiple selector types including element, class, ID, descendant, and pseudo-class selectors
6. Accessibility Improvements
Added alt text for all images
Added labels for all form inputs
Added HTML5 validation attributes
Improved colour contrast
Added keyboard focus states
Used semantic HTML for better screen reader support
7. How to View the Website
Clone or download the repository.
Open the project folder.
Open index.html in a browser or run with VS Code Live Server.

9. Reflection

This project improved my understanding of semantic HTML, accessibility, CSS styling, and debugging. The biggest challenge was identifying and fixing numerous intentional errors. By validating the code, improving structure, and implementing best practices, I created a professional and fully functional portfolio website that meets all project requirements.
