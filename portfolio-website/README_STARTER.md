Name: Claudelle Francis

## Project Overview

This project is a multi-page personal portfolio website created using HTML and CSS. The website showcases personal information, skills, projects, and contact details. The goal of the project is to demonstrate knowledge of semantic HTML, CSS styling, responsive design principles, accessibility considerations, and web development best practices.

## Pages Included

1. Home Page
   - Introduction section
   - Hero image
   - Navigation menu

2. About Page
   - Personal background
   - Skills table
   - Profile image

3. Projects Page
   - Project showcase cards
   - Project descriptions
   - Responsive layout

4. Contact Page
   - Contact form
   - Input fields
   - Radio buttons and checkboxes

## CSS Features Implemented

- Element selectors
- Class selectors
- ID selectors
- Descendant selectors
- Attribute selectors
- Pseudo-classes (:hover, :focus, :nth-child)
- Flexbox layout
- CSS Grid layout
- Responsive design using media queries
- Box model properties (margin, padding, border)
- Table styling
- Form styling
- Navigation hover effects

## Accessibility Considerations

- Semantic HTML structure
- Alternative text for images
- Improved colour contrast
- Focus states on form elements
- Readable font sizes and spacing
- Clear navigation structure
